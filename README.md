# techsilon-oss/.github

Org-wide files for [techsilon-oss](https://github.com/techsilon-oss):

- **[KIT-STANDARD.md](KIT-STANDARD.md):** the standard every kit follows.
- **[TRADEMARKS.md](TRADEMARKS.md):** how the Techsilon and kit names may be used.
- **Reusable workflows** that each kit's CI calls: [DCO](.github/workflows/dco.yml) and [plain words](.github/workflows/plain-words.yml).
- **Default community health files.** GitHub uses these for every repo in the org that has none of its own:
  - [SECURITY.md](SECURITY.md)
  - [CONTRIBUTING.md](CONTRIBUTING.md)
  - the [issue templates](.github/ISSUE_TEMPLATE)
- **[profile/README.md](profile/README.md):** the org's public profile page.

Change any of them through a pull request; `main` is protected.
