# techsilon-oss

Small, focused kits for building and shipping software with guardrails, published by Techsilon LLC and following one [kit standard](https://github.com/techsilon-oss/.github/blob/main/KIT-STANDARD.md). Each kit works from the command line with Git alone; the Claude Code plugins are an optional layer.

**License:** the kits move to the Apache License 2.0, each in its next release; earlier releases stay under the license they were published with. See each kit's `LICENSE`. "Techsilon" and the kit names are trademarks of Techsilon LLC ([TRADEMARKS.md](https://github.com/techsilon-oss/.github/blob/main/TRADEMARKS.md)).

| Kit | What it does |
|---|---|
| [govkit](https://github.com/techsilon-oss/govkit) | Claude Code plugin: project guardrails (branch flow, CI-fallback release gate, doc-sync, trackers) scaffolded into any repo, and kept current |
| [docs-kit](https://github.com/techsilon-oss/docs-kit) | One layout for `docs/`: a check that runs in your tests, a mover that keeps every link and path working, and setup, notes and how-tos from Claude Code |
| [qa-kit](https://github.com/techsilon-oss/qa-kit) | Claude Code plugin, in progress: feature records and test cases kept in step with the code |
| [release-gate-kit](https://github.com/techsilon-oss/release-gate-kit) | A local CI-fallback release gate: reproduce your CI checks on your machine when CI can't run |
| [gh-runner-kit](https://github.com/techsilon-oss/gh-runner-kit) | Self-hosted GitHub Actions runners with automatic fallback to GitHub-hosted |
