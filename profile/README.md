# techsilon-oss

Small, focused kits for building and shipping software with guardrails. They're MIT-licensed, published by Techsilon LLC, and all follow one [kit standard](https://github.com/techsilon-oss/.github/blob/main/KIT-STANDARD.md).

| Kit | What it does |
|---|---|
| [govkit](https://github.com/techsilon-oss/govkit) | Claude Code plugin: project guardrails (branch flow, CI-fallback release gate, doc-sync, trackers) scaffolded into any repo, and kept current |
| [qa-kit](https://github.com/techsilon-oss/qa-kit) | Claude Code plugin, in progress: feature records and test cases kept in step with the code |
| [release-gate-kit](https://github.com/techsilon-oss/release-gate-kit) | A local CI-fallback release gate: reproduce your CI checks on your machine when CI can't run |
| [gh-runner-kit](https://github.com/techsilon-oss/gh-runner-kit) | Self-hosted GitHub Actions runners with automatic fallback to GitHub-hosted |

Security: [SECURITY.md](https://github.com/techsilon-oss/.github/blob/main/SECURITY.md). Contact: oss@techsilon.com.
