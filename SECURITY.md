# Security

Thank you for taking the time to report a problem. **Please don't open a public issue for a vulnerability.**

## How to report

1. **On the affected repo, use "Report a vulnerability"** (the **Security** tab → **Report a vulnerability**). This opens a private advisory that only you and the maintainers can see, and keeps the discussion and the fix together.
2. **If that button isn't there, or you can't use it,** email **oss@techsilon.com**.

Include what you found, how to reproduce it, and the version (the kit's `v<version>` tag or the version in its manifest).

You'll get an acknowledgement, and then a fix or an assessment, as soon as it has been looked at.

## Supported versions

The latest release of each kit. Fixes ship as a new release; nothing is backported.

## Scope

The repositories in [techsilon-oss](https://github.com/techsilon-oss). Each kit's README says what it does on your machine, which is the best place to start when judging impact.
